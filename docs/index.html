Preguntas

Preguntas sobre la facturación electrónica

¿Necesito mi propio certificado digital?

Sí. El certificado digital se emite ante la DGII a nombre de la empresa y se carga en la cuenta. ECF Gateway no emite ni custodia certificados.

¿Qué pasa si se supera el límite de comprobantes?

La cuenta puede seguir operando y los comprobantes adicionales se facturan al final del mes. El plan puede cambiarse en cualquier momento.

¿Los datos de cada empresa quedan separados?

Sí. Cada organización mantiene separados sus comprobantes, clientes, usuarios y certificados.

¿La plataforma incluye API para integrar mi sistema?

Sí. La API REST permite emitir y consultar comprobantes electrónicos desde sistemas propios, con autenticación por token.
